# Support

## How to get help

- **GitHub Issues:** [Open an issue](https://github.com/OneByJorah/VirtOffice/issues) for bugs and feature requests.
- **Email:** [info@jorahone.com](mailto:info@jorahone.com) for private or time-sensitive matters.
- **Discussions:** Use the [discussions board](https://github.com/OneByJorah/VirtOffice/discussions) for usage questions and ideas.

## What to include in a bug report

- Repository and version/branch.
- Operating system and runtime version (Python/Node/PowerShell as applicable).
- Steps to reproduce.
- Expected vs actual behavior.
- Relevant logs or screenshots.

## Self-hosting support

These are self-hosted infrastructure tools. Support assumes you have basic familiarity with Docker, reverse proxies, and the relevant service protocols.

- Run services behind a reverse proxy (Caddy/Nginx) with TLS.
- Keep Tailscale/WireGuard as the preferred exposure model.
- Rotate secrets and API keys regularly.
- Bind services to localhost unless a reverse proxy handles TLS.
